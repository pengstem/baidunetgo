## 1 引言

### 1.1 编写目的

本文档描述 BaiduNetGo 要做什么、为谁做、做到什么程度算完成，是设计、实现、测试与验收的依据。读者是项目组成员、任课老师和测试人员。

### 1.2 项目背景

百度网盘是国内用户量最大的网盘，但它的桌面客户端有几个长期痛点：

1. **Linux 版体验差**：官方 Linux 客户端更新慢、界面陈旧、常年缺功能。
2. **客户端臃肿**：官方客户端基于 Electron/WebView，安装包大、内存占用高、启动慢。
3. **预览要先下载**：看一张图、一份 PDF、听一首歌，往往要先把文件下载到本地。
4. **传输参数不透明**：连接数、分块大小等全靠用户猜，不同会员等级、不同网络下的最优值差别很大。
5. **开源命令行工具门槛高**：BaiduPCS-Go 功能强，但只有命令行，普通用户用不了。

BaiduNetGo 想在三个平台（macOS / Windows / Linux）上提供一个**原生、轻量、能直接预览、会自己调优传输**的图形客户端。

### 1.3 范围

本期（v0.x）做：登录、浏览、预览、文件操作、上传下载、分享、离线下载、回收站、设置与自动调优，三平台打包与自动发布。

本期不做：百度网盘的同步盘/备份、相册 AI 分类、多账号同时在线、移动端。

### 1.4 术语

| 术语 | 含义 |
|---|---|
| BDUSS / STOKEN | 百度登录 Cookie 中标识身份的两个字段 |
| fs_id | 网盘中每个文件的唯一编号 |
| 秒传 | 服务器已有相同内容的文件时，只提交校验值、不上传内容 |
| 有界 Range | 形如 `bytes=a-b` 的 HTTP 分段请求；百度下载服务器只接受这种请求 |
| SVIP / VIP | 百度网盘会员等级，影响下载速度 |
| mpv | 开源媒体播放器，本项目用它播放视频 |
| fakepan | 本项目自写的"假网盘"服务，用于测试和演示 |

## 2 总体描述

### 2.1 产品定位

一个面向普通网盘用户、尤其是 macOS 和 Linux 用户的原生桌面客户端。外观参照 macOS 原生应用（侧边栏毛玻璃材质、彩色图标块、灰色分组面板），用 GPU 直接绘制界面，不带浏览器内核。

### 2.2 用户特征

| 用户类型 | 特征 | 主要诉求 |
|---|---|---|
| 普通用户 | 会用网盘 App，不懂命令行 | 扫码就能登录，看文件、下文件简单直观 |
| 重度用户 / 会员 | 文件多、传输量大 | 下载快、可断点续传、批量操作 |
| Linux 用户 | 官方客户端体验差 | 一个能用、好用的原生客户端 |

### 2.3 运行环境

- 操作系统：macOS 12+（通用二进制）、Windows 10+（amd64/arm64）、Linux（amd64/arm64，需要 GTK 3）
- 可选依赖：mpv（播放视频）
- 网络：能访问 pan.baidu.com 及其下载服务器

### 2.4 设计与实现约束

1. **纯 Go、不用 cgo**：保证从任意平台都能交叉编译到三平台。
2. **下载服务器只接受有界 Range**：不带 Range 或 `bytes=a-` 会返回 403，所有读取文件内容的地方都必须分段。
3. **不得泄露凭据**：登录凭据必须加密存储，密钥放系统钥匙串。
4. **第三方代码的许可证**：从 BaiduPCS-Go 移植的代码遵守 Apache-2.0，保留 NOTICE。

## 3 功能需求

### 3.1 账号与登录（F-LOGIN）

|---|---|---|
| F-LOGIN-01 | 显示二维码，用户用百度网盘 App 扫码后自动登录 | P0 |
| F-LOGIN-02 | 支持粘贴整段 Cookie 或 BDUSS+STOKEN 登录 | P0 |
| F-LOGIN-03 | 登录成功后保存会话，下次启动免登录；会话用 AES-GCM 加密，密钥存系统钥匙串，无钥匙串时退回 0600 权限的密钥文件 | P0 |
| F-LOGIN-04 | 本机已登录官方 Linux 客户端或 BaiduPCS-Go 时，自动沿用其登录 | P1 |
| F-LOGIN-05 | 显示头像、昵称、会员等级与到期时间、空间用量 | P1 |
| F-LOGIN-06 | 会话失效（errno -6/-4/111）时自动退回登录页；主动退出后不再自动导入其他客户端的登录 | P0 |

## 4 非功能需求

| 编号 | 类别 | 需求 | 衡量方式 |
|---|---|---|---|
| N-01 | 性能 | 界面保持流畅；20 行同时删除的粒子动画每帧绘制约 2 ms | `MYGO_FRAME_STATS` 统计 |
| N-02 | 性能 | 下载速度达到账号会员等级允许的 90% 以上 | 自动测速报告 |
| N-03 | 资源 | 不带浏览器内核，安装包与内存占用明显小于官方客户端 | 打包体积、任务管理器 |
| N-04 | 安全 | 凭据加密存储；重新开启 TLS 证书校验（依赖库默认关闭） | 代码审查 |
| N-05 | 安全 | 给 mpv 用的本地流服务只监听回环地址，每个文件一个随机令牌 | 代码审查、测试 |
| N-06 | 可移植 | 不使用 cgo，一条命令交叉编译三平台 | CI 构建 |
| N-07 | 可测试 | 不需要真实账号即可运行全部界面测试 | `go test ./...` 通过 |
| N-08 | 可维护 | `go vet`、`gofmt` 无告警；每次提交一件事 | CI |
| N-09 | 易用 | 界面全中文；交互与 macOS Finder 一致（删除即移入回收站、可撤销） | 走查 |
| N-10 | 可靠 | 传输状态持久化，崩溃或退出后不丢任务 | 测试 |

## 5 主要用例

### UC-1 扫码登录

- **参与者**：用户、百度网盘 App
- **前置条件**：本机没有可用会话
- **主流程**：① 应用显示二维码；② 用户用手机 App 扫码并确认；③ 应用轮询到确认结果，换取 Cookie；④ 加密保存会话；⑤ 进入文件页。
- **扩展**：二维码过期 → 自动刷新；本机有官方客户端/BaiduPCS-Go 的登录 → 跳过①–③直接导入。

### UC-2 预览一份 PDF

- **前置条件**：已登录
- **主流程**：① 用户双击 PDF；② 应用获取下载链接；③ 用有界 Range 分块读入内存；④ PDFium（WebAssembly）逐页渲染；⑤ 用户翻页、缩放、关闭。
- **扩展**：链接过期（403）→ 自动重新获取链接后继续；超过预览上限 → 提示下载。

### UC-3 下载大文件并断点续传

- **主流程**：① 用户选中文件点下载；② 任务入队，按设置的连接数分 4 MB 块并发下载到 `<文件>.bngdl`；③ 每完成一块记入 `.bngdl.json`；④ 全部完成后改名为正式文件并通知。
- **扩展**：用户退出应用 → 下次启动从已完成的块继续；断网 → 任务排队，网络恢复后继续。

### UC-4 分享文件

- **主流程**：① 选中文件 → 分享；② 设置提取码和有效期；③ 生成链接并复制；④ 在"我的分享"中可查看或取消。

## 6 验收标准

1. 第 3 节所有 P0 需求实现，并有对应的自动化测试或演示步骤。
2. `go test ./...`、`go vet ./...` 全部通过，`gofmt -l .` 无输出。
3. 用真实账号运行自测（`BAIDUNETGO_SELFTEST`），所有功能项通过。
4. CI 能产出三平台安装包并发布到 GitHub Release。
