# 汇报讲稿（10-26 项目规划书汇报，5 分钟）

> 9 页 PPT，每页约 30 秒。讲稿也写在 PPT 每页的演讲者备注里。

## 第 1 页 封面（0:15）

**BaiduNetGo** · 彭灵钰 · 2026.10

讲：大家好，我做的项目叫 BaiduNetGo，一个百度网盘的桌面客户端。用纯 Go 写，界面直接在 GPU 上画，三个平台都能用。

## 第 2 页 Credit goes to Opus 5.5（0:30）

讲：这个项目的功劳首先要归给模型。模型能力一直在变强，很多以前大家觉得不错的工程做法，现在已经用不上了。我的感受是：编程在很大程度上真的变成了许愿。我负责说清楚想要什么，代码交给模型写。

## 第 3 页 background：百度网盘太难用（0:30）

画面：限速 / 臃肿，元素混杂 / 使用不够优雅 / 复古体验拉满

讲：为什么做？因为百度网盘太难用了：限速；界面臃肿，元素混杂；用起来不够优雅；整体体验很复古。后面讲功能时会一条条对上。

## 第 4 页 architecture：MyGo（0:40）

画面：0.3 ms per frame · ≈1 s incremental build · <1 GB dev environment · 10.7 MB installer；“自行预览，very ai native”“初代版本只用一个 claude pro 5h session limit 即完成”

讲：技术选型是 MyGo，纯 Go 写桌面应用，界面直接用 GPU 画。几个实测数字：动画中一帧 0.3 毫秒；增量编译大约 1 秒；整个开发环境不到 1 GB；Windows 安装包 10.7 MB。它能在没有窗口时自己渲染界面做预览和测试，所以非常 AI native。初代版本只用了一个 Claude Pro 的 5 小时额度就做完了。

## 第 5 页 workflow：6 天，100 次 commit，2.1 万行 Go（0:35）

画面：103 条 prompt · 22 字中位数 · ≈50 个 session · 两台电脑 + 一部手机；右侧 PRD 全文

讲：我一共发了 103 条 prompt，一半以上不超过 22 个字，前后开了大约 50 个 session，经常同时开几个。右边是整个项目的需求文档：贴两个仓库链接，加两句话。

## 第 6 页 taste：我的 prompt 大多是在挑问题（0:30）

讲：这几句都是原话。我不写代码，我负责判断好不好看、合不合理，而且要说具体：比如设置里的单位 MB 应该写在名字旁边，因为写在右边对不齐。“优雅”这个词我说了 8 次。

## 第 7 页 workflow：怎么确认 AI 写对了（0:35）

讲：两件事。第一，让 AI 自己跑测试、截图：假网盘加 50 个界面测试，真账号自检，还能自己截图看界面。第二，纠正过的事写进 CLAUDE.md，以后每个 session 启动时都会读到。以前要人记住的 practice，现在写成一行规则交给模型。

## 第 8 页 features：主要功能（0:35）

讲：自动测速调参：按会员等级实测线路和连接数，16 个连接 16.7 MB/s，开到 48 个反而只有 6.6，连接数不是越多越好。不落盘预览：图片、PDF、音乐读进内存直接看，视频交给 mpv。分享链接：剪贴板里有链接就自动打开预览，勾选后转存。登录：直接导入本机已有的登录。

## 第 9 页 takeaway（0:20）

画面：代码可以交给 AI 写，需求和验收还得自己来。

讲：最后一句心得：代码可以交给 AI 写，需求和验收还得自己来。谢谢大家，欢迎提问。

## 演示（如有时间）

```bash
BAIDUNETGO_FAKE=1 go run .
```

## 问答准备

| 可能的问题 | 回答要点 |
|---|---|
| 代码是 AI 写的，你做了什么？ | 选题和技术路线、需求与追问、审美定调、试用和报问题、审查测试本身、取舍、验收；会话记录和提交历史可查 |
| 怎么保证 AI 写的代码是对的？ | 106 个测试（50 个界面测试）+ 假网盘 + 真实账号自检 + CI；举死锁、缓存失效、`TestPathFolds` 的例子 |
| 代码量怎么算的？ | Go 源码 17,401 行 + 测试 4,059 行，不含依赖库；统计命令在项目管理文档里 |
| 用了别人的代码吗？ | 依赖 MyGo、BaiduPCS-Go 两个开源库；上传流程移植自 BaiduPCS-Go，遵守 Apache-2.0 并保留声明 |
| 会不会被百度封号？ | 用的是网页版同样的接口；自检只在临时文件夹中进行并清理 |
| 和官方客户端比有什么优势？ | 不带浏览器内核、安装包 10.7 MB、不落盘预览、自动调优、分享链接自动打开、Linux 能用 |
| 内存占用多少？ | 如实说：常驻约 210 MB（假网盘，含内置图片和 PDF 引擎），优化在下一阶段计划里 |
| 下一步做什么？ | 与官方客户端对比测评、内存优化、Windows/Linux 实机走查、公开仓库并启用自动更新 |
